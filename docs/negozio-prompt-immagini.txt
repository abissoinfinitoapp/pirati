PROMPT PER LE IMMAGINI — IL NEGOZIO DELLE COSE INUTILI
=====================================================

30 oggetti. File finali: assets/negozio/<id>.webp  (quadrati 1:1, 1200x1200).
Se un file manca, il gioco mostra un'icona 🛍️ di riserva: nessun blocco.

STILE COMUNE (da anteporre a ogni prompt)
-----------------------------------------
"Product photography of a single small toy object, centered, on a clean plain
off-white / very light grey seamless background, soft even studio lighting, gentle
shadow beneath, slightly playful, high detail, no text, no logos, no packaging text,
no watermark, square 1:1 framing. The object looks like a cheap fun collectible."

REGOLE PER LE FIGURE DI PERSONE (calciatori / eroi / cartoni)
------------------------------------------------------------
- NON somiglianti a persone reali: sono giocattoli di plastica in stile "action
  figure" generica, proporzioni da bambolotto, articolazioni visibili, vernice
  lucida. Nomi inventati, niente stemmi o loghi di squadre o marchi reali.
- Colori dei completi/costumi generici (blu, rosso, verde...), niente scritte.
- Espressione buffa e amichevole, mai realistica o minacciosa.
